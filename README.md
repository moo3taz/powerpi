📊 Company Revenue & Growth Analysis Dashboard
This project is an end-to-end data analysis solution designed to transform over 10,000 company records into actionable business insights using Power BI.

🚀 Project Overview
The main objective of this dashboard is to track revenue trends, identify top-performing companies, and visualize market performance across different regions. By applying clean data modeling and advanced DAX, I was able to build a performance-optimized dashboard that helps in strategic decision-making.

🛠 Tech Stack
Data Tooling: Power BI Desktop (Power Query & DAX).

Data Modeling: Star Schema design for optimized reporting.

Visualization: Interactive mapping, custom charts, and drill-through capabilities.

📈 Key Technical Highlights
Performance Optimization: Optimized the model to handle 10k+ rows efficiently by cleaning and transforming data within Power Query.

Advanced DAX Measures:

Dynamic ranking (Top 10 Companies).

Revenue and growth calculations.

Context-aware filtering using CALCULATE and ALL functions.

Data Modeling: Implemented a clean Star Schema, ensuring that facts and dimensions are properly related to prevent performance bottlenecks.

🔍 Key Insights
Concentration of Revenue: The top 10 companies contribute approximately 36% of total revenue.

Regional Trends: Visualized market distribution across different tags and geographies to highlight high-potential regions.
